# Licensing

## This project's own code

`app/`, `seed/`, `tests/`, `harness.py`, `report.py` and `web/app.js` are ours.

## Ext JS

The front end uses **Ext JS 7.0, which is GPL v3**. Version 7.0 was the last
release Sencha published under GPL; everything after it is proprietary.

GPL v3 is a copyleft licence. Distributing an application built with Ext JS
under the GPL means the application's source has to be GPL v3 as well, and a
public repository counts as distribution. Two ways to be clean about it:

1. **Licence this repository GPL v3.** Download the official text from
   https://www.gnu.org/licenses/gpl-3.0.txt, save it as `LICENSE` in the project
   root, and put a short header on your own source files.
2. **Keep the repository private** and share it with the judges directly.

The Ext JS build itself is not committed here, so nothing of Sencha's is being
redistributed by this repository as it stands. The obligation attaches when you
distribute the running application.

Nothing above is legal advice. If it matters to your submission, check with the
organisers which they expect.
